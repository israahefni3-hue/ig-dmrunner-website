# IG DM Runner — Landing Website

A lightweight, static landing page intended for a pre-launch Chrome extension. Hosted on GitHub Pages. No build tools, backend, or JavaScript dependencies.

## Contents

- `index.html` — complete website, features, contact, pre-launch pricing, draft refund policy and privacy notice.
- `assets/early-prototype-en.svg` — English concept interface illustration (not an actual app screenshot).
- `assets/early-prototype-ar.svg` — Arabic right-to-left concept illustration (not an actual app screenshot).
- `.nojekyll` — ensures GitHub Pages serves static files directly.

## Before publishing

1. The contact email in `index.html` is from the connected GitHub account. **Confirm it is okay to publicly display** or replace it with your intended business support email.
2. Review and formally approve the **draft 14-day refund policy** before accepting any payments.
3. Replace illustrated previews with real verified IG DM Runner screenshots before advertising released functionality.
4. Do not represent a pre-release or unverified automation capability as working, policy-compliant, or approved.
5. Provide actual Chrome Web Store and checkout links only after those listings exist and have been approved.

## Publish using GitHub Pages

1. Create a **public** repository named `ig-dmrunner-website` under your GitHub account.
2. Upload `index.html`, `.nojekyll`, and the `assets` folder at the root of the `main` branch, preserving folder paths.
3. In repository **Settings → Pages → Build and deployment**, choose **Deploy from a branch**.
4. Choose branch **main** and folder **/(root)**, then click **Save**.
5. Wait for GitHub Pages to complete deployment and verify the published address, expected to be:

   `https://YOUR_USERNAME.github.io/ig-dmrunner-website/`

6. Check that screenshots load, navigation works, and the URL is publicly accessible before using the URL for Lemon Squeezy.

## Important

GitHub Pages deployment is separate from account verification, checkout approval, and Chrome Web Store approval. A public landing page alone does not guarantee payment-provider approval.
